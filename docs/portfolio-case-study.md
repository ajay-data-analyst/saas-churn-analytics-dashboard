# Portfolio Case Study

## Project
SaaS Subscription & Churn Analytics Dashboard

## Role
Power BI Developer / Data Analyst

## Objective
Demonstrate data preparation, semantic modeling, DAX, Power BI UX, retention analysis, churn analysis, customer risk analysis, and technical documentation.

## Approach
The project started from a flat customer churn dataset and was reframed into a SaaS subscription analytics model.

Development progressed through:
1. Baseline audit
2. Page 3 visual troubleshooting
3. Semantic model review
4. DAX and metric-definition corrections
5. UX and design polish
6. Business narrative audit
7. Documentation
8. Repository preparation and validation

## Technical Stack
- Power BI Desktop
- Power Query/M
- DAX
- PBIP/PBIR
- Power BI Modeling MCP
- Power BI Report Authoring CLI
- pbi-cli
- Git/GitHub
- MySQL as a supporting/reference tool

## Key Engineering Decisions
- PBIP became the source of truth.
- Working configurations were preserved.
- Bookmark-dependent visuals were not deleted.
- Measure names were corrected when terminology could overstate the data.
- Realized revenue replaced unsupported predictive LTV claims.
- Cohort MRR Momentum replaced unsupported true NRR terminology.
- Date-table configuration and chronological sorting were validated.

## Final Dashboard
1. Executive Overview
2. Customer Churn
3. Retention & Cohort
4. Customer Value

## Portfolio Value
The project demonstrates structured troubleshooting, semantic-model discipline, DAX quality control, UX refinement, documentation, validation, and source-controlled Power BI development.

## Important Limitation
This is a portfolio project. It is not represented as a real client deployment and does not claim real client business outcomes.
